# Sphere Experiment

Expérimentation Three.js : sphère avec shader de couleur custom basé sur le bruit de Ashima (`ashima.vert` + `basicColorSphereFrag.frag`), rendu via `ShaderMaterial`.

## Stack

- Three.js + GLSL (glslify)
- ES6 via Babel/Browserify (gulp)

## Installation

```
npm install
gulp server
```
